# AI-Powered Lead Qualification & Scoring Automation

An automated sales lead processing workflow built using Zapier, YouForm, Apollo API, JavaScript, PostgreSQL, Google Gemini, and Gmail.

## Project Overview

This project demonstrates an eight-step workflow designed to automate lead capture, enrichment, scoring, database storage, prioritization, and sales notifications.

## Workflow Architecture

![Lead Qualification Workflow](screenshots/lead-qualification-workflow.png)

## Technology Stack

- YouForm — Lead capture
- Webhooks by Zapier — Apollo API integration
- Code by Zapier — Lead scoring and priority classification
- PostgreSQL — Lead storage
- Filter by Zapier — High-priority lead filtering
- Google Gemini — AI-generated summaries and outreach drafts
- Formatter by Zapier — Email formatting
- Gmail — Sales notifications
