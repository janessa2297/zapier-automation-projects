**Key Features:**
- Automated lead capture using YouForm
- REST API enrichment integration configuration
- JavaScript-based lead scoring and classification
- PostgreSQL database integration
- Conditional filtering for high-priority leads
- AI-generated lead summaries and outreach drafts
- Automated Gmail sales notifications
