# Zapier Automation Projects

### AI-Powered Workflow Automation | API Integrations | JavaScript | QA Testing

A collection of workflow automation projects built using Zapier, Google Gemini, JavaScript, REST APIs, and third-party integrations.

This repository showcases practical experience in designing, implementing, testing, and documenting automated business processes.

## Featured Projects

### 1. AI-Powered Content Repurposing Automation

**Technologies:** Zapier, Google Drive, Google Gemini, AI by Zapier, Formatter by Zapier, Google Sheets

An automated content processing workflow designed to transform source audio/video content into multiple content formats.

**Key Features:**
- Google Drive file-based automation trigger
- AI-assisted content extraction and generation
- Two long-form blog posts
- Two Instagram posts
- Two LinkedIn posts
- Text formatting and content processing
- Google Sheets content logging

**Documentation:** [View Content Repurposing Project](content-repurposing-automation/)

### 2. AI-Powered Lead Qualification & Scoring Automation

**Technologies:** Zapier, YouForm, Apollo API, JavaScript, PostgreSQL, Google Gemini, Gmail

An eight-step lead processing workflow designed to automate lead intake, qualification scoring, conditional routing, and AI-assisted sales notifications.

**Key Features:**
- Automated lead capture using YouForm
- REST API enrichment integration configuration
- JavaScript-based lead scoring and classification
- PostgreSQL database integration
- Conditional filtering for high-priority leads
- AI-generated lead summaries and outreach drafts
- Automated Gmail sales notifications

### 3. Asana Task Lifecycle & Client Communication Automation

**Technologies:** Zapier, Asana, Paths by Zapier, Google Drive, Gmail, Delay by Zapier, Filter by Zapier

A multi-path automation workflow that responds to Asana task status changes and automates task management, client follow-ups, document retrieval, and email communications.

**Key Features:**

- Five conditional workflow paths based on Asana task status
- Automated Google Drive folder creation
- Automated Asana task creation
- Multi-stage client follow-up emails
- Delayed follow-up processing
- Gmail response checks and conditional filtering
- Google Drive PDF retrieval
- Automated welcome and service notifications

**Reported Testing Results:**

- All five configured workflow paths passed functional testing.
- Three successful Zap executions observed in Zap History.
- Additional negative and edge-case testing recommended.

**Documentation:** [View Asana Task Lifecycle Project](asana-task-lifecycle-automation/)
