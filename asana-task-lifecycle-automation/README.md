# Asana Task Lifecycle & Client Communication Automation

A multi-branch workflow automation project built using Zapier, Asana, Google Drive, Gmail, Delay by Zapier, and Filter by Zapier.

## Project Overview

This project demonstrates status-based workflow automation, connecting Asana task updates with Google Drive operations, automated email follow-ups, and client communication processes.

## Workflow Architecture

## Key Features

- Five conditional workflow paths
- Automated Google Drive folder creation
- Asana task creation
- Client follow-up email automation
- Delayed follow-up sequences
- Conditional response filtering
- PDF attachment retrieval
- Automated welcome and service emails
